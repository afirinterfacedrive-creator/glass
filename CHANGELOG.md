# Changelog

## 2.1.2

### ✨ Improvements

- Added customizable input font size through `GlassInputStyle`.
- Added centralized input font size defaults through `AppConstants`.
- Improved input appearance customization with configurable field height, padding, border radius, blur, background opacity, borders, shadows, and hover effects.
- Improved the separation between global appearance settings and component-specific settings.
- Improved the public package API and package architecture.
- Improved documentation for glass inputs and appearance customization.
- Updated package documentation and examples for the new `2.1.2` release.

### 🐛 Fixes

- Fixed input appearance configuration inconsistencies.
- Improved handling of input style defaults.
- Improved consistency between Universal Glass input styling and appearance configuration.

## 2.1.1

### ✨ Improvements

- Refined the appearance and theme system for greater flexibility and consistency.
- Added independent appearance profiles for Aqua, Classic, Light, and Dark modes.
- Improved theme persistence and migration from previous configuration formats.
- Enhanced glass surfaces, gradients, borders, shadows, glow, and hover effects.
- Improved reusable dialogs, modals, forms, inputs, toasts, and tooltips.
- Enhanced phone input support with country and operator data management.
- Improved the public API and overall package organization.
- Updated the example application and appearance settings experience.

### 🐛 Fixes

- Fixed several appearance and theme persistence issues.
- Fixed gradient density and related configuration handling.
- Improved UI consistency across glass components and settings.
- Improved package stability and test coverage.

## 2.1.0

### ✨ Improvements

- Prepared the package for pub.dev publication.
- Added GitHub homepage and repository metadata.
- Improved package structure and reusable glassmorphism components.
- Updated package metadata and versioning.

## 1.0.0

### 🎉 Initial Release

- Introduced the reusable Universal Glass Flutter UI component library.
- Added glassmorphism effects and reusable glass components.
- Added `UniversalAppBar` and tab support.
- Added `GlassButton` and `UniversalGlassButton`.
- Added `GlassThemeProvider` with theme persistence.
- Added reusable glass toggles and physical controls.
- Added Flutter and Riverpod integration.
